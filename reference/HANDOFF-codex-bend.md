# 별빛 마당 — 숙이기 동작 인수인계

## 실행과 수정
- 최신 실행 파일: starlight-yard-2d-motion.html
- 수정 소스: source/index.html, source/app.css, source/app.js, source/assets/
- 검사: node source/tests/verify.cjs
- 단일 HTML 생성: node source/tools/build-standalone.cjs
- 새 배포/게시 작업은 요청받지 않았으므로 수행하지 않았습니다.

## 이번 변경
42종에 공이 없는 숙이기 그림을 추가했습니다. 공을 잡은 아이는 내려가서 문 뒤 일어나고, 못 잡은 아이도 빈 입으로 내려갔다 일어납니다. 식사는 같은 자세로 숙인 채 작게 움직이다 일어납니다. 공을 놓친 동작은 한 번의 공놀이마다 한 번만 재생합니다. 실제 공은 한 아이만 가집니다.

몸을 비스듬히 밀거나 공만 떠오르게 하던 방식 대신, 머리와 앞다리를 굽힌 그림을 사용합니다. 중간 자세에서 얼굴이 겹치지 않도록 투명도 혼합을 사용하지 않습니다. 식사와 공놀이가 서로 끼어들 때 이전 예약 콜백을 무시합니다.

## 코드 위치
- BEND_DATA: 7개 새 bend-*.webp 자산의 좌표
- requestBend / getBendSprite: 동작 그림 로드·캐시
- bendCurve / bendAmount: 숙이기·식사 시간 진행
- startMissedBow / othersStop: 공을 놓친 아이의 동작
- beginBallGrab / updateBall: 공 소유와 입으로 옮기는 시점
- feed / bowlDone: 식사 도착·완료와 중단 처리

## 유지한 사항
현재 그림 무드, 낮·밤 마당, 기존 놀이/꾸미기/별 편지/백업 기능, 설정 안의 날짜 카드, 작은 동물 0.5배 / 골든·진돗개 1.2배, 동물 종류별 자동 소품을 유지했습니다. 저장 키 starlight-yard-v1과 데이터 구조는 바꾸지 않았습니다. 브라우저 localStorage 저장이므로 기존 앱에서 백업을 내보내 두는 편이 좋습니다.

고양이는 야옹만 하며 문장은 하늘 글자로 표시합니다. 기존 금지 문구와 기능 원칙도 유지합니다. 아이콘은 동물이 없는 버전입니다.

## 검증의 범위
검사 결과와 실제 렌더러에서 만든 미리보기는 최종 응답을 참고하세요. DOM 대역 + 실제 Canvas 검사를 사용하며, 실제 모바일 터치/브라우저 실행을 검증했다고 주장하지 않습니다. 실제 3D 모델은 포함하지 않습니다.

## 이미지 생성
기본 내장 image_gen 도구로 기존 각 동물의 이미지를 참조했습니다. 프롬프트: 각 줄에 같은 동물을 유지한 5열 × 6행 투명 스프라이트 시트. 정자세 → 25% 숙임 → 반쯤 숙임 → 75% 숙임 → 주둥이가 바닥에 닿는 자세. 뒷발 위치와 몸 크기를 고정하고 머리와 앞다리를 굽힘. 각 동물의 무늬·귀·꼬리·클레이 재질 유지. 새는 날개를 접고 부리를 내림. 공·그릇·음식·글자·격자·그림자 금지.

## 최종 확인 결과
- 42종 × 5개 자세, 총 210개 동작 그림 로드와 렌더링 확인
- 공 접근 → 숙이기 → 입 부착 → 귀환 확인
- 놓친 아이는 빈 입으로 제자리에서 숙였다가 일어남 확인
- 식사 도중 음식이 먼저 사라지지 않으며, 가족 모두 식사 완료 후 그릇 상태가 정리됨 확인
- 공을 던진 뒤 과거 식사 예약이 공 추적을 덮어쓰지 않음 확인
- 45개 자산, JavaScript 구문, 날짜 계산, 설정 안 날짜 카드 검사 통과
- 세 가지 캔버스 크기 렌더링 검사 통과
- 실제 앱 스프라이트 렌더러로 bend-actions-preview.gif 생성

실제 모바일 터치·브라우저 화면 검증은 아직 하지 않았습니다. 캐릭터별로 프레임 사이에 미세한 형태 변화는 남을 수 있습니다.
