# 별빛 마당 — 개발 인수인계 문서

> 펫로스(반려동물 상실)를 겪는 사람을 위한 잔잔한 힐링 반려동물 게임.
> 떠나보낸 아이들을 마당에 다시 불러 쓰다듬고, 밥 주고, 공놀이하고, 별 편지를 보내는 웹앱(단일 HTML).
> 이 문서는 지금까지의 결정 사항, 현재 구현, 코드 구조, 그리고 **다음 작업(동물 디자인 재작업)** 을 정리한 것입니다.

---

## 0. 가장 먼저 읽을 것 — 사용자(기획자)가 확정한 원칙

이 앱의 톤은 사용자가 여러 번 조정했습니다. 아래는 **반드시 지켜야 하는 규칙**입니다.

### 꼭 지킬 것
- **잔잔하고 따뜻하게.** 벌칙·실패·배고픔 게이지·아이가 아프거나 슬퍼하는 연출 없음. 오래 안 와도 아이는 반겨 주기만 함.
- **고양이는 말하지 않는다.** 고양이 말풍선은 `야옹 / 냐앙 / 미야옹 / 냥! / 먀아 / 골골골…`만. 고양이가 할 대사는 **하늘(배경)에 그냥 글자로** 띄움: 배경 상자 없이, 그림자 15% 정도(`rgba(59,35,64,0.15)`, blur 6, y+2). 강아지·토끼·햄스터는 말풍선으로 말함.
- **"울어도 괜찮아" 류 문구 금지.** 울음을 언급하는 문구는 넣지 않음.
- **후회 위로는 별 편지 안에서만.** 편지 내용에 후회가 담겨 있으면 아이가 알아서 위로함. 후회를 고르는 버튼/화면은 만들지 않음. 편지 내용은 어디에도 전송·공유하지 않음(기기 안에서 키워드로만 판단).
- **여러 마리 지원** (최대 5마리). 아이콘·대표 이미지에 특정 동물 한 마리만 넣지 않기("내 개는? 내 고양이는?" 문제).
- **가로·세로 화면 모두 지원.**
- 화면은 **단순하게**. 사용자는 별 편지/별자리/마음 화면이 "너무 디테일하다"고 해서 줄였음. 새 기능도 설명 문구 최소화.

### 하지 말 것 (사용자가 명시적으로 거절함)
- 봉사·기부 등으로 유도하는 기능
- 추모 공간 / "졸업"·배웅 의식 / 앱을 떠나보내는 엔딩
- 가족·친구와 함께 기억하기(공유) 기능
- 마음 상태 그래프·추이 기록 ("지난 2주의 마음" 같은 것)
- 연속 방문 스트릭, 안 오면 손해 보는 FOMO 장치
- "울어도 괜찮아" 문구
- 아이콘에 동물 그리기

### 좋다고 한 것
- 1분 같이 숨 쉬기
- 앱 밖의 하루로 이어 주는 **아이의 작은 부탁**(물 한 잔, 햇볕 5분 등 — 강요 없이)
- 문질러 쓰다듬기 (손을 **살짝 늦게** 따라오는 말랑한 모션)
- 밥 주기, 똥 치우기, 마당 꾸미기(켜고 끌 수 있게)
- 정면 모습(앉아서 나를 볼 때), 걷는 방향에 맞는 정면/뒷모습
- 입체감, 몽글몽글함

## 2. 기능 명세 (현재 구현)

### 2.1 아이들 소개 (최초 실행 / 설정 → "아이들 정보 바꾸기·추가하기")
- 최대 5마리. 아이별: 이름, 동물(고양이/강아지/토끼/햄스터), 종류(품종), 기억하고 싶은 날(선택), 한마디(선택), 사진(선택).
- 품종: 고양이 16종(치즈 코숏, 고등어 코숏, 삼색이, 턱시도, 까만, 하얀, 러시안 블루, 샴, 페르시안, 스코티시 폴드, 먼치킨, 노르웨이 숲, 브리티시 숏헤어, 랙돌, 벵갈, 아메리칸 숏헤어), 강아지 10종(말티즈, 푸들, 포메, 시바, 진돗개, 코기, 골든, 비숑, 닥스훈트, 누렁이), 토끼 5종, 햄스터 5종. 품종 선택 칸에 정면 미리보기.
- 사진은 280px로 줄여 JPEG dataURL로 저장 → 마당 왼쪽 뒤편에 아이별 액자로 섬. 누르면 크게 보기.
- 기억하는 날: 매년 그 날 마당에 케이크·풍선, 해당 아이가 정면으로 반김, 토스트 "오늘은 ○○의 날이에요".

### 2.2 마당 (메인 화면)
- 실제 시각을 따라 하늘이 바뀜(새벽/낮/노을/밤). 설정에서 고정 가능.
- 구름이 흐르고, 햇살 빛줄기, 꽃잎 날림, 은은한 블룸·비네트.
- 원근감: 멀리 있는 아이는 작게(`ds(depth)` 0.78~1.2), 발밑 부드러운 그림자.
- 아이들 AI: 돌아다니기 / 앉기(옆·정면) / 잠자기(밤에 더 자주, 방석 있으면 방석으로) / 서로 다가가 하트.
- 걷는 방향: 옆으로=옆모습, 아래로=정면 걷기(`fwalk`), 위로=뒷모습(`bwalk`).
- 떠다니는 빛(낮=민들레 씨앗, 밤=반딧불) 누르면 온기 +1.
- 가끔 마당에 쪽지 봉투가 놓임(하루 1번, 안 열어도 손해 없음) → 아이가 쓴 짧은 쪽지.

### 2.3 하단 메뉴 (5개)
1. **밥 주기** — 분홍 밥그릇 채움 → 아이들이 그릇 양옆으로 와서 먹음. 다 먹으면 비워짐. 먹은 뒤 18~45초 후 70% 확률로 귀여운 똥(최대 3개). 누르면 치워짐 + "고마워! 깨끗해졌다". 안 치워도 불이익 없음. 똥은 저장하지 않음.
2. **공놀이** — 마당을 누르면 공이 날아감. 공중에서 잡으면 "○○ 멋진 캐치!". 여러 마리면 **덜 잡은 아이가 우선**(속도 부스트) — 한 마리만 독차지하지 않게.
3. **별 편지** — 받는 아이 선택(여러 마리일 때만, "모두에게" 포함) + 글쓰기. 보내면 별이 되어 하늘로 올라감. 하늘의 별을 누르면 다시 읽기. "지난 편지 보기" 링크로 목록(쪽지 포함).
   - **후회 감지**: `REGRET_KEYS` 키워드(결정/안락사/일찍/몰랐/마지막/곁에 없/화냈/바빠/더 잘해/미안/후회…) → 카테고리별 위로 대사 `REGRETS`를 아이가 차례로 말함. 로컬 처리만.
4. **꾸미기** — 온기로 열리는 장식 13종, 각각 놓기/치우기 토글(`G.hidden`):
   꽃밭10 · 방석25 · 등불45 · 우체통55 · 풍경 나무70 · 하얀 울타리85 · 작은 연못100 · 무지개120 · 아이들 집140 · 해바라기160 · 나무 벤치180 · 나비200
5. **쉬어 가기** — "같이 숨 쉬기 · 1분"(4초 들숨·2초 멈춤·6초 날숨 × 5회, 원이 커졌다 작아지고 아이들도 같이 부풀었다 줄어듦) + **오늘의 작은 부탁**(하루 1개, "해 줬어요" → 마당에 튤립 1송이 + 아이가 꽃 옆으로 와서 고마워함, 안 해도 됨 문구).

### 2.4 상호작용
- 아이 **탭** = 쓰다듬기(하트, 정면으로 앉음).
- 아이를 **누른 채 문지르기** = 손 방향으로 천천히 기울고(스프링 감쇠) 눌렸다 부풀어 오름, 잠시 뒤 눈을 감음, 고양이는 골골송(소리 켰을 때). 문지른 거리마다 하트 + 쓰다듬기 카운트.
- 마당 빈 곳 탭 = 가장 가까운 아이가 그쪽으로 걸어감.

### 2.5 상단
- 마당 이름(설정에서 직접 지정 가능, 비우면 아이 이름으로 자동), 부제(품종·꽃 개수), 온기 게이지와 다음 해금, 소리 토글(펜타토닉 앰비언트 + 효과음 WebAudio), 설정.
- 설정: 마당 이름, 하늘 고정, 아이들 정보, 저장 안내, 상담 번호(정신건강 1577-0199, 자살예방 109).

### 2.6 대사
- `LINES`(any/종별/morning/night/together), 아이가 주기적으로 혼잣말. 고양이는 §0 규칙 적용(`say()` 안에서 분기).
- 문장은 반말, 다정하게. 탓하지 않기, 울음 언급 안 하기.

## 3. 데이터 (저장 상태 `G`)

```js
{
  family: [{ id, name, species: "cat"|"dog"|"rabbit"|"hamster", breed, motto, day: "YYYY-MM-DD", photo: dataURL|null }],
  yardName: "",            // 비우면 자동
  warmth: 0,               // 온기 (해금 기준)
  pats, catches, treats,   // 통계
  stars: [{ id, text, at, x, y, to: "all"|petId }],   // 별 편지 (x,y = 하늘 위치 0~1)
  notes: [{ at, from, name, text }], noteDate,         // 아이 쪽지
  favorDone: "YYYY-MM-DD", blooms, bloomSpots: [{x,d,c}],  // 작은 부탁 꽃
  hidden: ["rainbow", ...], // 치운 장식
  sky: "auto"|"dawn"|"day"|"dusk"|"night",
  breaths, visits[], moods{}, regrets,                 // 내부 기록(화면 노출 안 함)
  set: true, lastVisit, updatedAt
}
```
- `localStorage["starlight-yard-v1"]`에 저장 + (claude.ai 아티팩트 환경에서만) `window.claude.use("db")`로 `data/users/<id>/garden` 문서에 비공개 동기화. **다른 환경에서는 db 코드가 조용히 건너뛰어지고 localStorage만 사용됨.** 네이티브 앱으로 옮기면 이 부분을 기기 저장소/계정 저장소로 교체.
- `normalize()`가 옛 버전 데이터(단일 `pet`, `color` 등)를 마이그레이션함 — 필드 추가 시 여기에 기본값 추가.

## 4. 코드 구조 (`starlight-yard.html` 내 `<script>`, IIFE 하나)

| 섹션 | 핵심 |
|---|---|
| helpers | `mix/shade`(캐시된 색 보간), `hash`, `rand`, `clamp` |
| breeds | `BREEDS{cat,dog,rabbit,hamster}` — `pat`(tabby/spots/calico/tuxedo/point/bicolor/dutch/panda/stripe/solid), `base/light/dark`, `eye`, `ear`, `tail`, `fluffy/chunky/short/long` |
| sprite engine | 44×36 픽셀 그리드에 타원/사각형/삼각형/스트로크로 부위를 쌓고 **높이맵(z)** 을 기록 → `lightGrid()`가 법선 계산해 단계적 조명·AO·스펙큘러 → `outline()` → 캔버스. `face()`는 `det` 픽셀(조명 제외). 포즈: `walk/run/sit/sleep/eat/front/fwalk/bwalk`, 4프레임, 표정 `n/h/b/s`. `getSprite()` 캐시 |
| backdrop | 저해상도 캔버스(`lcv`, 픽셀 크기 `P`)에 하늘·구름·언덕·원근 잔디 그린 뒤 메인 캔버스로 확대 |
| decor | `decor()`로 장식을 한 번 그려 캐시, `place()`로 깊이별 크기로 배치. `drawScene()`이 깊이 정렬 렌더 |
| entities | `ents`(아이들), `updatePet()`(이동/상태/문지르기 스프링 `lean/leanV/press`), `decide()` |
| systems | 공(`throwBall/updateBall`), 밥/똥(`feed/bowlDone/spawnPoop/cleanPoop`), 빛(`glows`), 편지(`letterForm`, `findRegret`), 쪽지(`setupEnvelope/openNote`), 기념일(`checkSpecial`), 숨쉬기(`startBreath/endBreath`), 부탁(`FAVORS/renderFavor`), 꾸미기(`UNLOCKS/has/unlocked/renderDeco`) |
| UI | `.veil`/`.sheet` 모달들, `renderHud()`, 토스트·힌트 |
| main loop | `frame()` — 업데이트 → 배경 → 장면 → 빛줄기 → 밤 틴트 → 등불 → FX → 블룸 → 비네트 → `drawBgLine`(고양이 대사) → 말풍선 |

레이아웃: `resize()`가 화면 크기로 `P`(도트 크기 2~5), `groundY`(높이 520 미만이면 50%, 아니면 56%), `dMin/dMax`(하단 메뉴 높이 실측) 계산. `@media (max-height:520px)`에서 메뉴가 한 줄로 얇아짐.

## 5. 다음 작업 (Codex에게 요청)

### 5.1 [최우선] 동물 디자인 다시 하기
- 사용자는 현재 도트 스프라이트를 좋아했지만 **새로운 디자인을 원함**. 지금까지 시안 6개(`rejected-designs/`) 모두 거절: 
  - A 말랑 찹쌀떡 도트, B 반짝 스티커 도트, C 고해상도 디테일 도트
  - D 양모 펠트, E 수채화 그림책, F 별빛 반투명
  - 피드백: **"다 별론데 좀 색다르게 새로운 느낌은 없을까"**
- 요청 방식: **바로 적용하지 말고 3개 정도 미리보기 이미지로** 보여 주고 사용자가 고름. 각 시안은 같은 6마리(치즈 고양이, 턱시도 고양이, 웰시 코기, 말티즈, 토끼, 햄스터)를 정면 앉은 자세로 비교.
- 고른 뒤에는 모든 포즈(옆 걷기 4프레임, 정면 걷기, 뒷모습, 앉기, 정면 앉기, 잠자기, 먹기, 표정 4종)와 전 품종에 적용해야 함. 현재 `getSprite(sp, breed, pose, f, expr, side)` 인터페이스를 유지하면 나머지 코드는 그대로 동작함(스프라이트 원점: `AX=22`, 발 기준 `GROUND=35`, 입 위치 `m.mx/m.my`는 공 물기에 사용).
- 지켜야 할 것: 귀엽고 따뜻함, 입체감/몽글몽글함 선호, 고양이 수염, 볼 홍조, 정면 모습 자연스럽게, 품종 차이가 보일 것.
- 아이디어 방향(아직 시도 안 함): 클레이/점토 3D 렌더 느낌, 종이 오리기(페이퍼컷) 레이어, 둥근 벡터 플랫(아이콘풍), 색연필/크레파스, 로우폴리 3D, 실루엣+포인트 컬러 미니멀 등.

### 5.2 확인이 덜 된 부분
- 뒷모습 걷기(`bwalk`)는 화면 캡처로 확인 못 함.
- 문지르기 모션 속도(스프링 계수 `16`, 감쇠 `5.5`, press 상승 `2.2`/하강 `1.4`)는 사용자 피드백 대기.
- 똥 등장 장면 직접 확인 못 함.
- 맑은 낮 하늘에서 고양이 배경 글자(흰색)가 다소 흐림 → 필요 시 그림자 조금 진하게 또는 옅은 보라색 글자.

### 5.3 앱으로 만들 경우
- 현재는 단일 HTML. 앱스토어 출시를 고려한다면 모듈 분리(sprite/scene/systems/ui), 저장소 교체(§3), 홈 화면 아이콘(§1 icons) 적용.
- 화면 회전: 고정하지 말 것(가로·세로 모두).
