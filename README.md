# 별빛 마당

반려동물을 떠나보낸 사람이 아이들과 조용히 시간을 보내는 파스텔 마당 웹앱입니다.
아이들을 쓰다듬고, 밥을 주고, 공놀이를 하고, 별 편지를 보낼 수 있어요.

## 실행

Node.js가 있으면 추가 설치 없이 실행됩니다.

```sh
cd source
npm start      # http://localhost:8787
npm test       # 기본 검사 (문법·그림 파일·날짜 계산·설정 날짜 카드)
npm run build  # 그림·폰트를 모두 넣은 단일 파일 source/dist/starlight-yard.html 생성
```

소스 버전은 그림을 Canvas로 처리하기 때문에 HTTP 서버로 열어야 합니다. `npm run build`로 만든 단일 HTML은 브라우저에서 바로 열 수 있습니다.

## 폴더

| 경로 | 내용 |
|---|---|
| `source/index.html` | 화면 구조 |
| `source/app.css` | 화면 스타일 |
| `source/app.js` | 게임·저장·동물·날짜 로직 |
| `source/assets/` | 동물·걷기·배경·소품 그림과 폰트 (`assets-manifest.json`에 목록) |
| `source/tools/build-standalone.cjs` | 단일 HTML 빌드 |
| `source/tests/verify.cjs` | 기본 검사 |
| `icons/` | 앱 아이콘 (동물 없는 확정본) |
| `previews/` | 동물·걷기·마당 미리보기 |
| `reference/` | 승인된 동물 그림체, 이전 인수인계 문서, 수정 전 캡처 |
| `HANDOFF.md` | 현재 상태와 확정된 원칙 — **작업 전에 먼저 읽어 주세요** |
| `CLAUDE_PROMPT.md` | AI 도구에 작업을 넘길 때 쓰는 전달 문구 |

## 저장

브라우저 `localStorage`의 `starlight-yard-v1` 키에 저장합니다. 아이들·사진·별 편지 데이터를 초기화하는 변경은 하지 말아 주세요. 주소(파일·서버·도메인)가 바뀌면 기존 데이터는 자동으로 옮겨지지 않습니다.

## 지켜야 할 원칙 (요약)

- 잔잔하고 따뜻하게. 벌칙·실패·연속 방문 보상이나 결석 불이익 없음.
- 고양이는 말풍선에서 야옹·골골 소리만 내고, 문장은 하늘에 글자로 띄움.
- 울음을 권하는 문구를 넣지 않음. 후회 위로는 별 편지 안에서만.
- 봉사·기부 유도, 추모 공간·배웅 엔딩, 공유 추모, 마음 그래프는 넣지 않음.
- 최대 5마리, 가로·세로 화면 모두 지원. 앱 아이콘에는 동물을 넣지 않음.

자세한 내용은 `HANDOFF.md`를 참고하세요.
